## About

**Suit Pumpkin** is my personal professional portfolio, designed to showcase my work, experience, projects, and creative practice as a software developer.

My approach combines **software development, game development, visual design, and creative problem-solving**, with a particular interest in building interactive and meaningful digital experiences.

The portfolio itself is designed as an extension of my professional identity: clean, expressive, and intentional without sacrificing personality.

---

## Brand Identity

**Suit Pumpkin** represents the intersection between **professionalism and authentic creativity**.

The visual identity is built around four principles:

| Principle                  | Description                                                          |
| :------------------------- | :------------------------------------------------------------------- |
| **Elegant simplicity**     | Clean compositions, negative space, and clear visual hierarchy.      |
| **Professional character** | A restrained visual language that communicates technical competence. |
| **Creative expression**    | Subtle details and interactions that reflect my creative background. |
| **Intentional design**     | Every visual element serves a communicative or functional purpose.   |

### Visual System

| Element           | Value          |
| :---------------- | :------------- |
| Background        | `#262626`      |
| Text              | `#F2F0EF`      |
| Red accent        | `#AC393B`      |
| Gold accent       | `#B39148`      |
| Primary typeface  | **Sora**       |
| Branding / labels | **Montserrat** |

## Tech Stack

This portfolio is built with a modern React-based frontend stack:

| Technology                  | Purpose                                |
| :-------------------------- | :------------------------------------- |
| **React 19**                | Frontend framework                     |
| **Vite**                    | Development environment and build tool |
| **React Router DOM 7**      | Client-side routing                    |
| **Tailwind CSS 4**          | Utility-first styling                  |
| **Framer Motion**           | UI animations and transitions          |
| **Lucide React**            | Interface icons                        |
| **react-simple-typewriter** | Hero section typewriter effect         |

## Development

### Requirements

* Node.js
* npm

### Installation

```bash
git clone https://github.com/SuitPumpkin/[repository-name].git
cd [repository-name]
npm install
```

### Available Scripts

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Run ESLint
npm run lint

# Preview production build
npm run preview
```

## Deployment

The project is configured for deployment with **Vercel**.

Production builds are generated in:

```text
dist/
```

The repository includes a `vercel.json` configuration file for deployment.

## Design Philosophy

The portfolio is intentionally treated as more than a collection of projects.

It is a small interactive product that communicates **who I am, what I build, and how I approach creative and technical problems**.

The design prioritizes:

* Clear information hierarchy
* Minimal and intentional interfaces
* Subtle motion
* Strong typography
* Visual consistency
* Accessibility and usability
* A balance between technical and creative identity
